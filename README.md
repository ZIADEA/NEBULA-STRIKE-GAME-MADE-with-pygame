# NEBULA STRIKE

A space-based action game developed with Python and Pygame, featuring dynamic gameplay, engaging mechanics, and immersive visuals.

## Overview

NEBULA STRIKE is a 2D arcade-style shooter game built with Pygame. Players navigate through space environments, encounter challenges, and engage in intense combat scenarios. The game combines classic game design principles with modern Python development practices.

## Features

- Dynamic spaceship controls and responsive input handling
- Enemy AI systems with varied behavior patterns
- Collision detection and physics-based gameplay
- Score tracking and progression systems
- Smooth graphics rendering and animation
- Sound effects and audio management
- Multiple game states (menu, gameplay, pause, game over)

## Requirements

- Python 3.7 or higher
- Pygame library

## Installation

1. Clone the repository:
```bash
git clone https://github.com/ZIADEA/NEBULA-STRIKE-GAME-MADE-with-pygame.git
cd NEBULA-STRIKE-GAME-MADE-with-pygame
```

2. Install required dependencies:
```bash
pip install pygame
```

3. Run the game:
```bash
python main.py
```

## How to Play

- Use arrow keys or WASD to move your spaceship
- Use mouse or spacebar to fire projectiles
- Avoid enemy attacks and obstacles
- Eliminate enemies to increase your score
- Survive as long as possible

## Controls

| Action | Key(s) |
|--------|--------|
| Move Up | W / Up Arrow |
| Move Down | S / Down Arrow |
| Move Left | A / Left Arrow |
| Move Right | D / Right Arrow |
| Fire | Spacebar / Mouse Click |
| Pause | P |
| Quit | ESC |
